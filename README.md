# MandiSaathi 🇮🇳

MandiSaathi is a voice-first, mobile-first web assistant designed to break linguistic barriers in India’s local mandis. The solution focuses on enabling clear communication between vendors and buyers who speak different Indian languages, supported by AI-driven price understanding and contextual mandi information.

---

## Problem

In local Indian markets, language differences often create confusion, mistrust, and unfair trade outcomes. Many buyers and vendors struggle to communicate clearly, especially when they do not share a common language.

---

## Solution

MandiSaathi addresses this challenge by acting as a **real-time linguistic bridge**:

- 🎙️ Voice-based multilingual communication between vendors and buyers  
- 💰 AI-assisted explanation of fair local price ranges  
- 📍 Discovery of nearby mandis with basic timing information  

The platform is intentionally designed as a **mobile-first web solution**, suitable for on-ground use where smartphones—not laptops—are available.

---
